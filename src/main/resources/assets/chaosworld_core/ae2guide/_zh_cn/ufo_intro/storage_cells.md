# 高容量存储元件

欢迎来到 UFO Future 存储科技！  
我们的存储元件超越了原版 AE2 的容量限制，**所有系列均可在一个盘里混存任意资源类型**（物品、流体、化学品等），如同 OMNI 量子系列。

使用高强度天体物质锻造，具有极高的字节容量。
