# 多方块等级

通用多方块使用共享的 MK 等级系统。

## 配方锁定
- MK1 控制器运行 MK1 配方。
- MK2 控制器运行 MK1 和 MK2 配方。
- MK3 控制器运行 MK1、MK2 和 MK3 配方。

如果机器等级低于配方等级，配方保持锁定。

## 等级加成
当高等级多方块运行低等级配方时，获得自动缩放：

- 时间：每高于配方一级减半。
- 能量：每高于配方一级降至 75%。

示例：
- MK2 机器运行 MK1 配方 = 2x 速度且减少 25% 能量
- MK3 机器运行 MK1 配方 = 4x 速度且减少 43.75% 能量

## 为什么重要
升级等级不仅是为了解锁新配方。它还将旧生产线压缩为更快的后台吞吐量。

这使后期基地能够在玩家转向更重型的模拟和多方块自动化时保持旧链运行。
