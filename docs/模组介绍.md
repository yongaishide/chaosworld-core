# 乱界核心 · Chaos World Core

> Minecraft **1.21.1** · NeoForge **21.1.x** · 站在 **AE2** 与 **UFO Future** 肩上的终局科技扩展
> 模组 ID：`chaosworld_core` · 当前版本：`1.0.1`

**一句话版**：把"自动化"从机器级推到星系级——用 ME 网络喂料，用恒星模拟生产，用白矮星存东西。

---

## 这是什么

乱界核心是 ChaosWorld 整合包的核心模组。它不另起一套工业体系，而是以 UFO Future 的量子多方块与恒星物理为底座，补齐**材料线、机器线、存储格式与跨模组联动**，并把原本"能造但不好用"的环节打磨成真正能跑的自动化产线。

玩家见到它的第一台机器是**次元物质装配器（DMA）**，最后一座建筑是**恒星联结平台（Stellar Nexus）**。中间隔着的是一条从"电路板"到"恒星坍缩"的完整科技曲线。

---

## 核心内容

### 一、量子多方块产线

一套由控制器 + 外壳 + 仓口拼装的多方块体系，全部直连 ME 网络：

| 机器 | 职责 |
| --- | --- |
| 次元物质装配器（DMA） | 入门机。带热量系统与催化剂插槽，产出处理器、催化剂、星体物质与多种流体 |
| 量子物质制造机（QMF） | DMA 的多方块进化版，面向 AE2 大批量自动合成 |
| 量子切片机 | 批量加工印刷电路部件 |
| 量子处理工厂 | 批量精加工处理器 |
| 量子低温锻炉 | 低温工艺，产出稳定冷却剂等高级流体 |
| 量子样板供应器 | **72 组样板**的 AE2 样板仓，为整条线供料 |

- **MK1 / MK2 / MK3 分级**：高等级解锁更高级配方，并自动加速旧配方。
- 配套**量子超机械外壳、熵点外壳、引力子镀层外壳**等成型材，以及 ME 大型输入/输出/流体仓口。
- 冷却剂、热量、催化剂三套系统彼此牵制：快，就要付出热量与能耗的代价。

### 二、恒星联结平台（Stellar Nexus）

终局建筑。模拟真实恒星物理过程做超大规模生产：

- 模拟配方：红巨星坍缩、铁核聚变、钻石高压、中子轰击、超新星收割、恒星合成……
- **恒星场生成器 Mk.I ~ Mk.III** 提供场强等级，决定能跑哪些配方。
- **安全模式**：过热自动停机；**超频模式**：10 倍能耗换 5 倍速度与热量。
- 热量失控 = 灾难性爆炸。**请务必开着安全模式。**
- 直接从 ME 网络抽取能量与燃料，产物直接入库。

### 三、巨型存储

按"天体"分级的 AE2 存储体系，可插入 ME 驱动器 / ECO 驱动器：

| 系列 | 容量档位 |
| --- | --- |
| 白矮星元件 | 1G / 4G / 16G / 64G / 256G |
| 中子星元件 | 1T / 4T / 16T / 64T / 256T |
| 脉冲星元件 | 1P / 4P / 16P / 64P / 256P |
| 量子全能矩阵 | 16G ~ 256P 共 **13 档**，支持全部键类型（物品 / 流体 / 能量 / 化学品） |
| 存储组件 | 40M / 100M / 250M / 750M，直至**无限存储组件** |

元件另有 **Echo / Beacon / Nexus / Core / Singularity** 五级前缀强化。配套能量单元：Event Horizon Energy Cell、Quantum Energy Cell。

### 四、电路组装机与龙魂锻炉

两条 Mekanism 风格的加工线，各带 **8 级工厂**（基础 / 高级 / 精英 / 终极 / 绝对 / 至尊 / 寰宇 / 悖论无限），并行份数依次为 **3 / 5 / 7 / 9 / 11 / 13 / 15 / 17**：

- **电路组装机**：能量 + 化学物 → 电路。给机器注入化学品，看齿轮转动。
- **龙魂锻炉**：以能量与化学物熔铸龙魂、锻造成器；催化剂分"消耗 / 保留"两类，JEI 中有标注。

### 五、虚脉钻探机

不挖方块，直接从"虚拟矿脉"里抽矿：

- 矿脉按**陨石碎片 → 陨石 → 小行星 → 行星 → 恒星 → 星云 → 星系** 7 级递进，按维度分布，抽取权重写在数据包里。
- 矿物池可统一、可按钻头等级解锁；JEI 提供完整矿脉池查询页。
- 钻头升级：64 个 N 阶锭 → N+1 级；9 级钻头 + 九阶锭 → **无限钻头**。
- 自动化开关齐备：自动扫描、自动修复、自动拉取、自动弹出、自动维护。矿脉绑定靠**虚拟矿脉核心**。

### 六、材料体系

- **金属线**：冰雪、暮色合金、巫神、混沌金属、神龙金属、飞龙金属、全能合金、量子、不锈钢、圣金源、炫彩
- **科技线**：一阶 ~ 九阶科技材料
- 每种材料齐备 **锭 / 粒 / 板 / 粉 / 齿轮 / 棒** 六种形态 + 块，纹理采用可配置的染色方案（九阶颜色可在配置文件中改）
- **星体物质进阶**：原生质 → 实体物质 → 白矮星物质 → 中子星物质 → 脉冲星物质 → 暗物质 → 不稳定白洞物质；另有核星 → 中子素球 → 富集中子素球 → 带电富集中子素球
- **催化剂**：物质流 / 时序 / 超流 / 量子，各 T1~T3，分别影响速度、能耗、失败率与额外掉落，可软上限叠加

### 七、装备

- **量子永恒工具组**：剑（击杀成长）、镐（自动熔炼 + 渐进时运）、斧、锄、铲、锤（可变尺寸模式）、巨剑、法杖、弓、钓竿
- **星界联结套装**：无限护甲、绝对免伤、百万倍伤害反射、创造飞行、辐射免疫
- **现实撕裂者**：无限伤害，连创造模式玩家也能击穿
- **热阻套装**：抗热护甲

### 八、流体、收容与实用工具

- 流体：UU 物质 / UU 放大液、寒冰之尘 / 凝胶寒冰、液态星光、太初物质、原始星体等离子、超越物质、时间流体、空间流体、稳定冷却剂等
- **以太封存胶囊（ACC）** 存危险流体，**安全封存物质（SCM）** 收危险物品
- **凋灵召唤重构**：搭建结构 + 手持苦难核心右键，召唤 4000 血强化凋灵
- **结构终端**：扫描 / 自动建造 / 拆解多方块，从 ME 取材料，支持幻影全息预览与无线接入点远距离取料
- 游戏内 **GuideME 图文指南**（按 Guide 键）、**JEI** 全配方分类与 3D 结构预览、**Jade** 状态显示

## 跨模组联动

| 模组 | 联动内容 |
| --- | --- |
| **AE2**（必需） | 多方块直连 ME；72 组样板仓；巨型存储单元；样板 / 供料 / 产物全自动 |
| **ExtendedAE+**（必需） | 优化 ExIOPort 批量处理；恒星模拟可量产 Entro 水晶 |
| **AE2 Lightning Tech**（必需） | 深度接入 IO 端口、存储服务与 Tick 速率系统 |
| **Thunderbolt Core**（必需） | 使用其快速自动合成规划器处理大规模任务 |
| **NeoEcoAE**（必需） | ECO 驱动器联动；与 OmniCells 共同解锁 ECO - LE9 存储矩阵等级体系 |
| **AE2 OmniCells**（必需） | 量子全能矩阵基于其全能存储后端，13 档容量 |
| **Botania**（可选） | **把魔力做成 AE2 键类型**：魔力可存进 ME 网络、被导入/导出总线搬运；新增福鲁伊克斯魔力池；AE2 内部库存（充能器、分子装配室等）也可被魔力灌注 |
| **FTB Quests**（可选） | 新增 AE 资源任务与化学品任务，可统计 ME 网络库存；任务检测卡让无线终端接入统计 |
| **Mekanism**（可选） | 量子仓口直接存取化学品；化学品可进 ME；恒星模拟新增冶金激增 / 乙烯富集 / 裂变堆工艺；套装免疫辐射 |
| **AppFlux**（可选） | 从无线能量网络取 FE 为 AE 储电物品充电 |
| **ProjectE / Project Expansion**（可选） | 炼金转换接口与 ME 存储互通 |
| **Advanced AE**（可选） | 恒星模拟量产高级量子产物 |
| **KubeJS**（可选） | 注册与编辑恒星模拟等自定义配方 |
| **Jade / JEI / GuideME / GeckoLib**（可选） | 状态显示 / 配方与结构预览 / 图文教程 / 动画渲染 |

底层还有四十余个 Mixin 补丁，用于修正与增强 UFO / AE2 / 凋灵等既有内容的行为（多方块闪电需求、QMF 动态镜面、样板仓菜单与缓存、大整数存储单元等）。

## 上手路线

1. **起步**：电路组装机 + 材料线，把 AE2 的处理器产能拉起来
2. **成型**：搭起 DMA，进入量子多方块时代，接上样板供应器实现全自动
3. **扩张**：上量子工厂 / 低温锻炉，把巨型存储单元塞进驱动器
4. **终局**：恒星联结平台 + 场生成器 Mk.III，用恒星模拟批量产出一切
